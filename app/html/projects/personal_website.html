This Website

I made this website to showcase what I have made, who I am, and what I believe in. It is also a good exercise in making websites and in maintaining a project long term.

Technologies

Python with FastAPI

I picked Python with FastAPI as the web server because it is simple, fast enough, and I have some previous experience with it.

HTML, CSS, and JavaScript

It is a website, so I am stuck with these three. I chose not to add any extra stuff on top of these in order to keep the process of running the server simple and free of extra build steps.

Docker

Docker is, in practice, a bad choice for a project this small. I am only deploying to one low performance server, so the performance overhead of Docker does not provide enough benefit in other places to be worth it. Fortunately, I did not choose to use Docker for the convenience, but instead to get some experience with how Docker works.

Github Actions

I used Github Actions for continuous deployment of the website. This is another thing that is not necessarily worth the time investment at this scale, but knowing how to set up a continuous deployment pipeline is a useful skill.
